## Projects

- **[deterministic-swing-trading-research](https://github.com/PranavMulakala/deterministic-swing-trading-research)**: paper-only ETF swing-trading research in Python. Checkpointed data ingestion, SHA-256 integrity checks, and a hash-chained SQLite event journal so every result can be reproduced.
- **[WaterFilterRobo](https://github.com/PranavMulakala/WaterFilterRobo)**: can a robot arm refurbish a used water purifier? Triage, cleaning, and membrane assembly, built and tested in MuJoCo/LeRobot simulation.
- **[StockMarketApp (Tape)](https://github.com/PranavMulakala/StockMarketApp)**: turns a stock's price tape into rated "plays", the way a sports app turns a game into plays, so everyone in a room sees the same move at the same moment. TypeScript, with a deterministic, unit-tested play engine.
- **[BrokerDocs](https://github.com/PranavMulakala/Shipping_Crate_Project)**: a clickable React/TypeScript mockup of a freight-broker document tool (rate confirmations and bills of lading) that I use for customer-discovery demos.

I also built diagnostics APIs and an LLM triage eval for the open-source project superglue.
